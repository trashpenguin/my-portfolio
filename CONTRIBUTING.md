# Contributing

Thanks for your interest! This is a personal portfolio, but you're welcome to fork it and use it as your own.

## Using this as a template

1. Fork the repository
2. Clone your fork
3. Edit `src/portfolio.js` with your own information
4. Run `npm install` then `npm start` to preview locally
5. Deploy with `npm run deploy`

## Reporting issues

If you find a bug or have a suggestion, feel free to [open an issue](https://github.com/trashpenguin/my-portfolio/issues).
